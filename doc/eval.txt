Static Evaluation of position
=============================

Piece Values

  150 - Pawn
  400 - Knight
  400 - Bishop
  525 - Rook
  973 - Queen

End game

  Total value of all pieces less or equal 3000

Pawns

  50 for each row after double step in endgame
  15 for supporting pawn
 -25 double pawn

Rooks

 100 for conneccted rooks
  50 if not endgame and same row

King

-100 for edge position in end game
  15 for L1 distance per row/col in end game


Move Evaluation
===============

Rook

 -10 for giving up castling rights before game move 13

Queen

  75 queen exchange if positional value above/below 50/-50
-100 for moving before game move 5

King

  20 for castling
 -25 for giving up castling rights
