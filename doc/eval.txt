Static Evaluation of position
=============================

Piece Values

  100 - Pawn
  325 - Knight
  350 - Bishop
  500 - Rook
  990 - Queen

End game

  Total value of all pieces less or equal 3000

Pawns

  50 for each row after double step in endgame
  25 for supporting pawn
 -50 double pawn

Rooks

 100 for conneccted rooks
  50 if not endgame and same row

King

  15 for L1 distance per row/col in end game


Move Evaluation
===============

Rook

 -25 for giving up castling rights before game move 13

Queen

  75 queen exchange if positional value above/below 50/-50
 -50 for moving before game move 5

King

  50 for castling
 -50 for giving up castling rights

Capture bonus matrix (not applied currently)

    P    R    N    B    Q
   10  100  100  100  100          // pawn
    0   50    0    0   50	   // rook
    0   50   25   25   50          // knight
    0   50   25   25   50          // bishop
    0    0    0    0    0          // queen
    0    0    0    0    0          // king
